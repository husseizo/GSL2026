# Support

## How to get help

- **Questions about how AIOS works** — check the [Documentation Map](README.md#documentation-map) first; most "how does X work" questions are answered in a phase decision log or capability specification.
- **Something looks broken** — open a [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md).
- **You want to propose a change or new capability** — open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) or, for anything touching architecture/governance boundaries, an [Architecture Proposal](.github/ISSUE_TEMPLATE/architecture_proposal.md).
- **General questions** — open a [Question](.github/ISSUE_TEMPLATE/question.md) issue, or use GitHub Discussions if enabled (see [`docs/github-discussions.md`](docs/github-discussions.md) for the intended category structure).
- **Security concerns** — never a public issue; see [SECURITY.md](SECURITY.md).

## What this is not

This repository does not currently offer a commercial support contract, SLA, or a public product support channel — see the Roadmap's own [Product Strategy](docs/strategy/AIOS_ENTERPRISE_ROADMAP_V1.md#22-aios-product-strategy) section: AIOS is, today, an internal enterprise platform for Molas Solutions, not a licensed, externally-supported product.

## Response times

This project does not currently commit to a specific response-time SLA. Issues and questions are addressed as maintainer time allows.
