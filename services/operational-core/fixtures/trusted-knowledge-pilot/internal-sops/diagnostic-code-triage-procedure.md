# Diagnostic Code Triage Procedure

## Reading codes

Connect the diagnostic tool and record every real fault code returned, including manufacturer-specific codes, not just generic OBD codes. Do not clear a code before it has been recorded on the job card.

## Freeze frame data

Where the diagnostic tool captures freeze frame data (engine load, coolant temperature, RPM at the time the code was set), record it — this data helps distinguish an intermittent fault from a fault present at every startup.

## Suspected cause versus confirmed cause

A suspected cause identified from a fault code must be verified by a real physical inspection or test before a repair is authorized. A fault code alone is never sufficient evidence to replace a part.

## Repeat repair flag

If the same fault code has been recorded on the same vehicle within the last 90 days, flag the case as a repeat repair and escalate to a senior technician for root-cause investigation before repeating the same repair action.
