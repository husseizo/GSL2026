# Torque Specification Lookup Procedure

## Before tightening any fastener

Technicians must confirm the real torque specification for the exact vehicle model, engine code, and fastener position before tightening — never rely on memory or a similar-looking vehicle's specification.

## Lookup order

1. Check the vehicle's own approved technical bulletin for the specific fastener, if one is registered in the Knowledge Platform.
2. If no bulletin exists, check the manufacturer's official service documentation held on file.
3. If neither source is available, escalate to the senior technician before proceeding — never estimate a torque value.

## Recording

Every torque value applied to a safety-critical fastener (wheel bolts, suspension mounts, brake caliper bolts) must be recorded on the job card with the source of the specification cited.

## Calibration

Every torque wrench must be calibration-checked every 6 months. A wrench without a valid calibration sticker must not be used for safety-critical fasteners.
